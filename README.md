# Processamento de Dados Complexos com Python 🚀

Repositório avançado em Python focado em limpeza, tratamento inteligente de valores nulos, criação de métricas e agrupamentos estatísticos automatizados utilizando as bibliotecas Pandas e NumPy.

## 📋 Funcionalidades
- **Padronização Automática:** Limpeza e normalização de nomes de colunas.
- **Tratamento de Dados Ausentes:** Imputação inteligente de nulos (mediana para dados numéricos e marcação padrão para textos).
- **Criação de Regras de Negócio:** Cálculo dinâmico de métricas e colunas derivadas.
- **Sumarização Estatística:** Agrupamentos por categoria utilizando agregações complexas (`groupby`).
- **Exportação Automatizada:** Geração de novas planilhas tratadas prontas para relatórios.

## 🛠️ Tecnologias Utilizadas
- **Python** (versão 3.x)
- **Pandas** (manipulação e análise de dados)
- **NumPy** (operações numéricas avançadas)
